# STM32 Öğrenme

Blue Pill (STM32F103C8T6) ile gömülü sistem öğrenme sürecim.
Her klasör ayrı bir konu / deney.

## İçindekiler

* **01-harici-led** — Breadboard üzerinde harici LED, PA1 ile blink.
* **02-timer-blink** — TIM2 zamanlayıcısı kullanarak LED'i HAL\_Delay olmadan yakıp söndürme.
* **03-buton-timer** — Butona basınca timer tabanlı flaşör başlıyor/duruyor.
* **04-pot-adc** — Pot ile flaşör hızı (ADC → timer).
* **05-pwm-led —** PWM ile pot kontrollü parlaklık.
